# data-pipeline

Core data ingestion and transformation pipeline for the Horquva platform. Handles extraction from upstream sources, normalization, and loading into the organization's canonical data store, forming the backbone that downstream analytics and reporting depend on.

## Architecture & Stack
- **Extraction**: Batch-oriented API polling & change data capture
- **Processing**: Python data transformations & schema validation
- **Team Owner**: Engineering (`Ahmed Abubakr`)
